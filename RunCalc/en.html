RunCalc.exe

日本語ページ (Japanese)

RunCalc is a simple calculator designed to run on Windows 7 / 8 / 10 / 11.

It features lightweight and high-speed execution, working smoothly even on low-spec PCs.

Key Features

  • Instant calculations directly from the Windows "Run" dialog (Win + R)

How to Use

  1. Press Win + R, type rc [expression] (e.g., rc 1+1), and hit Enter.
  2. The result will be displayed and automatically copied to your clipboard. (Will not copy if an error occurs)
  3. You can also click Calc... to perform multiple calculations continuously.

※ Use half-width characters. (Use * for multiplication, / for division)
