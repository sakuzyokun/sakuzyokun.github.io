RunCalc.exe

English Page

RunCalc は Windows 7 / 8 / 10 / 11 で動作する、シンプルな計算機です。

高速な動作を特徴としており、古いPCでも快適に実行できます。

主な機能

  • 「名前を指定して実行 (Win+R)」からの高速計算

使用方法

  1. Win + R を押し、rc 計算式（例: rc 1+1）と入力してEnter
  2. 答えが表示され、自動的にクリップボードにコピーされます（エラー時はコピーされません）
  3. また、Calc... を押すと連続で計算が可能です

※半角で入力（掛け算は *、割り算は / を使用）
